BEFORE YOU START

  • Who can do this: someone with the Global Administrator role, or SharePoint Administrator plus Reports Reader.
  • Time: about 30 minutes, most of it waiting for downloads.
  • What you'll end up with: a handful of CSV files. Save them in one folder so the upload is quick.
  • Privacy: the files contain site names, sizes, activity counts and guest email addresses. They contain no document contents. I use them only for your findings pack and delete them 90 days after your findings call.

STEP 0 · OPTIONAL BUT HELPFUL

Show real site names in the usage reports

By default, Microsoft hides site and user names in usage reports and shows random codes instead. The reports in Step 2 are far more useful with real names. Only a Global Administrator can change this.

  1. Go to admin.microsoft.com and sign in.
  2. In the left menu, select Settings, then Org settings.
  3. On the Services tab, select Reports.
  4. Untick Display concealed user, group, and site names in all reports, then select Save.
  5. Wait a few minutes before running Step 2. You can tick the box again once you've uploaded everything.

If your organisation's privacy policy doesn't allow this, skip it. I can still work with the concealed reports.

REPORT 1 · ABOUT 5 MINUTES

SharePoint active sites

A list of every SharePoint site: how big it is, who owns it, when it was last used and whether it's shared outside the organisation.

  1. Go to admin.microsoft.com. In the left menu, select Show all, then under Admin centers select SharePoint.
  2. In the SharePoint admin center, select Sites, then Active sites.
  3. Make sure the view (top right) is All sites.
  4. Select the arrow next to any column heading, then Customize columns. Tick all of these: Site name, URL, Teams, Storage used, Primary admin, Hub, Template, Last activity, Date created, Created by, Sensitivity, External sharing, Files, Page views. Select Save.
  5. Select Export on the command bar. Save the CSV file.

REPORT 2 · ABOUT 10 MINUTES · THREE SMALL EXPORTS

Usage for SharePoint, OneDrive and Teams

Shows which sites, OneDrives and teams are actually used, and which have gone quiet.

  1. Go to admin.microsoft.com. In the left menu, select Reports, then Usage.
  2. SharePoint: select View more on the SharePoint card (or choose SharePoint from the list), open the Site usage tab, set the period to 180 days, then select Export.
  3. OneDrive: go back to Usage, open the OneDrive report, open the Usage tab, set 180 days, then select Export.
  4. Teams: go back to Usage, open the Microsoft Teams report, open the Team usage tab, set the longest period available, then select Export.

Tab names move around a little between tenants. If you can't find one, export what you can see and mention it in the notes when you upload.

REPORT 3 · ABOUT 10 MINUTES

Guests, and who can see what

Part A, everyone: the list of guest accounts.

  1. Go to entra.microsoft.com and sign in.
  2. Select Users, then All users.
  3. Select Add filter, choose User type, set it to Guest, then Apply.
  4. Select Download users, give the file a name, then Start. When it's ready, open the download link and save the CSV.

Part B, only if you have Microsoft 365 Copilot licences or SharePoint Advanced Management: the site permissions report. This is the single most useful report for Copilot readiness.

  1. In the SharePoint admin center, select Reports, then Data access governance.
  2. Under the snapshot reports, open Site permissions across your organization and select Get report (or Run report).
  3. The report can take a few hours. When it's ready, select Download and save the CSV.

Don't see Data access governance? That's fine. Skip Part B and let me know in the notes.
